# AI エージェント コース — ラボ一覧

画像の枠: **赤枠** ＝ クリック・選択・確認する場所、**青枠** ＝ 入力する場所。

このコースでは、Microsoft Foundry を使って AI エージェントを構築・拡張するスキルを習得します。

---

## コース全体の流れ

```
00 環境構築ガイド（共通リファレンス）

01 → 02a → 02b ─┬─ 03（独立ラボ）
                └─ 04 → 05
```

> **1 日目の演習 01 で作成した Foundry プロジェクト（East US 2）は、1〜4 日目のすべての演習で共用します。** 演習 01 では、このプロジェクトを Foundry Toolkit に設定し、1 日目の演習 01 でデプロイした gpt-5-mini モデル（TPM 10K）が使えることを確認します（演習 02a・02b・04・05 で使用）。  
> **演習 03 は専用の Azure AI Search とストレージ アカウントを作成します**が、プロジェクトは共用のものを使用します。リソースの削除は、4 日目の演習 06 の「クリーンアップ」でまとめて行います。

## 共通の事前準備

すべてのラボを開始する前に、以下が整っていることを確認してください（いずれも演習環境に準備済みです）。

- Visual Studio Code（最新版）
- Foundry Toolkit 拡張機能（VS Code 用）— インストール済み
- Python `3.13` 以降（推奨: `3.13.12`）
- アクティブな Azure サブスクリプション
- 各演習のスターター コード（`Labfiles/` 配下）— 配置済み。クローンは不要
