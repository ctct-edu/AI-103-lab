# Voice Live エージェントの開発

音声対応の AI エージェントを使用すると、話し言葉による指示や質問を行い、音声で応答を受け取る、という会話形式のやり取りができます。

この演習では、Microsoft Foundry Tools の Azure Speech の **Voice Live** 機能を使用して、リアルタイムの音声ベースのエージェントを作成します。

この演習の所要時間は約 **30** 分です。

> **注意**: この演習で使用する一部のテクノロジーはプレビュー中または開発中のため、予期しない動作、警告、またはエラーが発生する場合があります。

> **重要**: この演習は、話しかけて音声で応答を聞く **リアルタイムの会話** が中心です。マイクとヘッドセットが使えない場合は、この手順書の後半にある「マイクが使えない場合」を参照してください。

## 前提条件

この演習を開始する前に、以下を準備してください。

- 1 日目の演習 01 の完了（1 日目で作成した Foundry プロジェクトを共用します）
- Visual Studio Code、Python 3.13 以降、Azure CLI（演習環境にはインストール済みです）
- マイクとヘッドセット（推奨）

> **注意**: **1 日目の演習 01** で作成した **East US 2** のプロジェクトを使用します。[Voice Live をサポート](https://learn.microsoft.com/azure/ai-services/speech-service/regions?tabs=voice-live) し、[Foundry の音声ベースのエージェントをサポート](https://learn.microsoft.com/azure/foundry/agents/concepts/limits-quotas-regions#supported-regions) するリージョンのうち **West US 3** 以外のリージョンで使用してください。

## 共用の Foundry プロジェクトを開く

1. Web ブラウザーで [Microsoft Foundry ポータル](https://ai.azure.com)（`https://ai.azure.com`）を開き、1 日目の演習 01 で作成したプロジェクト（例: **AI103-Lab01-YYYYMMDD-XX**）を開きます。ページ上部の **[新しい Foundry]**（New Foundry）トグルがオンになっていることを確認します。

1. プロジェクトのホーム ページで、プロジェクト エンドポイントを確認します。**Foundry リソース名** と **プロジェクト名** も控えておいてください。

    > **ヒント**: **[プロジェクト エンドポイント]** は `https://<Foundry リソース名>.services.ai.azure.com/api/projects/<プロジェクト名>` の形式です。ホスト名の先頭部分が Foundry リソース名、`/projects/` の後ろがプロジェクト名です。Foundry リソース名はプロジェクト名から推測できないため、必ずエンドポイントに表示された名前を、そのまま使用してください。

## エージェントの作成

1. プロジェクトのホーム ページの **[エージェントの構築]** で **[エージェントの作成]**（Create agent）を選択します（または、左側のナビゲーション ペインで **[エージェント]**（Agents）を選択します）。**[エージェントの作成]** ダイアログで、**[エージェント名]** に `chat-agent` と入力し、**[対話モデル]** は既定の **[テキスト]** のままにして、**[作成]**（Create）を選択します。

    エージェントの準備ができると、エージェント プレイグラウンドが開きます。

    > **注意**: エージェントの作成時に、モデルの選択は求められません。エージェントには既定で **gpt-5** が選ばれます。[対話モデル] は作成後に変更できません。

1. エージェント プレイグラウンドの **[モデル]** で、1 日目の演習 01 でデプロイした **gpt-5-mini**（TPM 10K）を選択します。

1. エージェントの **[手順]**（Instructions）欄に、次の指示を設定します。

    ```
    あなたは、AI と関連トピックに関する情報の検索を支援する AI アシスタントです。質問には簡潔かつ正確に回答してください。
    ```

1. **[保存]**（Save）ボタンで変更を保存します。

1. **[チャット]**（Chat）ペインに次のプロンプトを入力して、エージェントをテストします。

    ```
    あなたは何を手伝ってくれますか？
    ```

    エージェントが指示に基づいた適切な回答を返すはずです。

## Azure Speech Voice Live の構成

Foundry エージェントの音声モードを有効にすると、Azure Speech の Voice Live が統合され、エージェントに音声機能が追加されます。

1. 左側のペインの、モデル選択リストの下にある **[音声モデル]**（Voice mode）トグルをオンにします。

    **[構成]**（Configuration）ペインが自動的に開かない場合は、チャット インターフェイスの上にある歯車のアイコンを使用して開きます。

1. **[構成]** ペインの **[音声モード]** で、既定の **[音声入力]**（音声認識モデル: **Azure Speech**、言語: **自動検出**）と **[音声出力]**（音声: **Ava Dragon HD Latest** など）の構成を確認します。使用する声が決まるまで、さまざまな声を試して試聴できます。

    ![エージェント プレイグラウンドと [構成] ペインのスクリーンショット。赤枠は [モデル] の gpt-5-mini、[音声モデル] トグル、[音声入力]、[音声出力] の [音声]。](../Media/d3e06-01-voice-mode-configuration.png)

    > **注意**: 既定の音声（**Ava Dragon HD Latest**）は、日本語の文章を読み上げません。ポータルのチャットで日本語の応答を音声で聞く場合は、**[音声出力]** の **[音声]** の一覧で **[その他の音声]** を選択し、**[音声の選択]** ダイアログの **[言語]** で **日本語 (日本)** を選んで、日本語の音声（**Nanami Dragon HD Latest** など）を選択し、**[保存]** を選択します。**[音声入力]** の言語は **自動検出** のままで、日本語で話しかけられます。

    ![[音声の選択] ダイアログのスクリーンショット。赤枠は [言語] の 日本語 (日本)、Nanami Dragon HD Latest、[保存] ボタン。](../Media/d3e06-02-select-japanese-voice.png)

1. **[構成]** ペインを閉じ、**[保存]** ボタンでエージェントを保存します。

## 音声を使用したエージェントとのやり取り

1. チャット ペインの「話しましょう」の下にある **[開始]**（Start）ボタンを使用して、エージェントとの会話を開始します。システムのマイクへのアクセスを求められたら、許可します。

    エージェントが音声セッションを開始し、プロンプトを待ち受けます。

1. アプリのステータスが **[聞いています…]**（Listening…）になったら、「*音声認識はどのように動作しますか?*」のように話しかけて、応答を待ちます。

1. アプリのステータスが **[処理中…]**（Processing…）に変わることを確認します。アプリが音声入力を処理します。

    > **ヒント**: 処理速度が非常に速いため、ステータスが *[話しています…]*（Speaking）に切り替わるまでの間に、処理中のステータスが見えない場合があります。

1. ステータスが **[話しています…]**（Speaking…）に変わると、アプリはテキスト読み上げを使用してモデルからの応答を音声で伝えます。元のプロンプトと応答をテキストで表示するには、チャット画面の下部にある **cc** ボタンを選択します。

    > **ヒント**: 続けてプロンプトを送るには、話しかけるだけです。エージェントの話に割り込んで、やり取りを必要な内容に集中させることもできます。チャット ペインの **[生成を停止]**（Stop generation）ボタンを使用すると、長い応答を停止できます。このボタンは会話を終了します。エージェントを引き続き使用するには、新しい会話を開始する必要があります。

1. 会話を続けるには、「*音声合成はどのように動作しますか?*」のように別の質問をして、応答を確認します。

1. エージェントとのチャットが終わったら、**X** アイコンを使用してセッションを終了します。会話のトランスクリプトが表示されます。

## クライアント アプリケーションの作成

カスタム アプリケーションでエージェントを使用するには、Azure Speech Voice Live SDK を使用して会話セッションを開始・管理するコードを記述する必要があります。

1. **chat-client** フォルダーを右クリックし、**[統合ターミナルで開く]** を選択します。ターミナルが **chat-client** フォルダーで開いていることを確認します。

1. ターミナルで次のコマンドを入力して、演習用にあらかじめ構築済みの仮想環境 (`labenv`) を有効化します。

    ```
    .\labenv\Scripts\Activate.ps1
    ```

    > **注意**: 必要な Python パッケージ (Foundry SDK、Azure Identity、Voice Live SDK など) は `labenv` に事前インストール済みです。`pip install` を再実行する必要はありません。

1. **.env** ファイルを開き、構成値を更新します。
    - **AZURE_VOICELIVE_ENDPOINT**: Foundry リソースの **エンドポイント**（Foundry ポータルのプロジェクト ホーム ページのプロジェクト エンドポイントから、`.com` ドメインまでの基本 URL だけを使用します）
    - **AZURE_VOICELIVE_PROJECT_NAME**: プロジェクトの名前
    - **AZURE_VOICELIVE_AGENT_ID**: エージェントの名前（**chat-agent**。この名前は大文字と小文字が区別されます）

    > **重要**: 貼り付けたエンドポイントから「/api/projects/{プロジェクト名}」のサフィックスを削除してください。エンドポイントは `https://{Foundry リソース名}.services.ai.azure.com` の形式にします。

1. 構成ファイルを保存します（**Ctrl+S**）。

### アプリケーション コードの実装

1. **chat-client.py** ファイルを開き、既存のコードを確認します。アプリケーションの骨組みの大部分はすでに用意されています。Voice Live SDK を使用してエージェントとの会話を管理するために必要な、主要なステップを実装します。

1. ファイルの先頭の既存の参照の下にあるコメント **名前空間のインポート** を見つけて、必要な名前空間をインポートする以下のコードを追加します。

    ```python
    # 名前空間のインポート
    from azure.identity.aio import AzureCliCredential
    from azure.ai.voicelive.aio import connect
    from azure.ai.voicelive.models import (
        InputAudioFormat,
        Modality,
        OutputAudioFormat,
        RequestSession,
        ServerEventType,
        AudioNoiseReduction,
        AudioEchoCancellation,
        AzureSemanticVadMultilingual,
        AzureStandardVoice,
        AgentConfig
    )
    ```

1. **main** 関数では、構成ファイルからエンドポイントを読み込むコードと、認証用の資格情報を取得し、**VoiceAssistant** オブジェクトを作成して実行するコードがすでに用意されています。

    **VoiceAssistant** クラスは、Voice Live の会話を管理するロジックをカプセル化します。

1. **main** 関数の下にある **VoiceAssistant** クラスの定義を見つけます。

    オブジェクトを初期化する **\_\_init\_\_** 関数はすでに実装されています。

    会話セッションを確立するための中心となる関数 **start** を、これから実装します。

1. コメント **ステップ 1: Azure VoiceLive をエージェントに接続** を見つけて、以下のコードを追加します（**try:** ステートメントの下に 1 レベル分インデントします）。

    > **ヒント**: **try:** の直下にある `pass  # コードを追加したら、この行は削除してかまいません` の行は、`try:` ブロックが空にならないようにするための仮の行です。ステップ 1 のコードを追加したら、この行は削除してかまいません。

    ```python
    # ステップ 1: Azure VoiceLive をエージェントに接続
    async with connect(
        endpoint=self.endpoint,
        credential=self.credential,
        api_version="2026-01-01-preview",
        agent_config=self.agent_config
    ) as connection:
        self.connection = connection
    ```

1. コメント **ステップ 2: オーディオ プロセッサを初期化** を見つけて、以下のコードを追加します（先ほど追加したステップ 1 のコードの下に、さらに 1 レベル分インデントします）。

    ```python
    # ステップ 2: オーディオ プロセッサを初期化
    self.audio_processor = AudioProcessor(connection)
    ```

    **AudioProcessor** は、コード ファイルの下の方で定義されている、音声ハードウェアの入出力を管理するユーティリティ クラスです。

1. コメント **ステップ 3: セッションを構成** を見つけて、以下のコードを追加します（上のステップ 2 のコードと同じインデントを維持します）。

    ```python
    # ステップ 3: セッションを構成
    await self.setup_session()
    ```

    このコードは、適切な音声形式、会話のターン検出の方式、エコーや背景ノイズを処理するオプションでセッションを構成します。

    > **重要**: 日本語を話すため、**setup_session** 関数の `RequestSession` には、応答の音声として日本語の音声を指定する、次の行があらかじめ用意されています。
    >
    > ```python
    > voice=AzureStandardVoice(name="ja-JP-Nanami:DragonHDLatestNeural"),
    > ```
    >
    > この指定は、エージェントに設定された音声を、このセッションだけ上書きします。英語の応答も、同じ音声で読み上げられます。

1. コメント **ステップ 4: オーディオ システムを開始** を見つけて、以下のコードを追加します（上のステップ 3 のコードと同じインデントを維持します）。

    ```python
    # ステップ 4: オーディオ システムを開始
    self.audio_processor.start_playback()

    print("\n✅ 準備完了! 話しかけてください...")
    print("Ctrl+C で終了します\n")
    ```

    このコードは、オーディオ プロセッサを開始します。これにより、マイクの音声入力を監視し、音声出力を再生します。

1. コメント **ステップ 5: イベントを処理** を見つけて、以下のコードを追加します（上のステップ 4 のコードと同じインデントを維持します）。

    ```python
    # ステップ 5: イベントを処理
    await self.process_events()
    ```

    このコードは、音声入力、応答出力、割り込みなどのイベントを処理するメイン ループを実行します。

1. コード ファイルに加えた変更を保存します。

    完成した関数は次のようになります。

    ```python
    # この try ブロックにコードを追加します!
    try:
        # ステップ 1: Azure VoiceLive をエージェントに接続
        async with connect(
            endpoint=self.endpoint,
            credential=self.credential,
            api_version="2026-01-01-preview",
            agent_config=self.agent_config
        ) as connection:
            self.connection = connection

            # ステップ 2: オーディオ プロセッサを初期化
            self.audio_processor = AudioProcessor(connection)

            # ステップ 3: セッションを構成
            await self.setup_session()

            # ステップ 4: オーディオ システムを開始
            self.audio_processor.start_playback()

            print("\n✅ 準備完了! 話しかけてください...")
            print("Ctrl+C で終了します\n")

            # ステップ 5: イベントを処理
            await self.process_events()

    finally:
        if hasattr(self, 'audio_processor'):
            self.audio_processor.shutdown()
    ```

## マイクが使えない場合

Voice Live は、話しかけた音声をリアルタイムで受け取り、音声で応答する **イベントベースの会話** のサービスです。この演習のクライアント アプリケーション（**chat-client.py**）も、マイクとスピーカー（またはヘッドセット）を直接操作します。

**chat-client.py** は起動するとすぐにマイクからの音声を送信し続けるため、マイクがない環境では会話を確認できません。マイクが使えない場合は、次のように進めてください。

1. **イベントの流れを確認する**: 会話は、次のイベントの流れで進みます。
    - ユーザーが話し始める（入力音声バッファーの音声開始イベント）→ 再生中の音声が停止される
    - ユーザーが話し終える → エージェントが「考えて」から応答する
    - 応答の音声チャンクを受信してキューに入れ、スピーカーで再生する

1. **マイクなしで進められる範囲を進める**: マイクが必要なのは、音声セッションを開始する操作と、アプリケーションの実行だけです。次の手順は、マイクがなくても実施できます。
    - 「エージェントの作成」: `chat-agent` を作成し、指示を保存し、**[チャット]** ペインに文字を入力して応答を確認する。
    - 「Azure Speech Voice Live の構成」: **[音声モデル]** トグルをオンにし、**[構成]** ペインで声を選んで試聴する（試聴にはスピーカーが必要です）。
    - 「アプリケーションの構成」と「アプリケーション コードの実装」: 仮想環境の作成、**.env** の編集、**chat-client.py** へのコードの追加。

1. **コードを読んで理解する**: 完成版のコードは `Labfiles_Ans/06-voice-live-agent` フォルダーにあります。ステップ 1〜5 の流れと、**handle_event** 関数でイベントの種類ごとに処理を分けていることを確認します。
