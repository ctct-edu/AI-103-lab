# AI-103 3日目 自然言語ソリューション — ラボ一覧

画像の枠: **赤枠** ＝ クリック・選択・確認する場所、**青枠** ＝ 入力する場所。

3日目のコースでは、Microsoft Foundry と Foundry Tools を使って、テキスト分析・音声・翻訳のソリューションを構築・拡張するスキルを習得します。

---

## コース全体の流れ

```
00 環境構築ガイド（共通リファレンス）

01 → 02 → 03 → 04 → 05 → 06 → 07
```

> **1 日目の演習 01 で作成した Foundry プロジェクト（East US 2）は、1〜4 日目のすべての演習で共用します。** 3 日目では、新しいプロジェクトを作成しません。演習 02〜07 は、基本的に順番を入れ替えられます（演習 05 は演習 02 の後）。演習 05 では、2 日目の演習 03 で作成したストレージ アカウント `ai103stgXXYYYYMMDD` を再利用し、コンテナー `files` を追加します。リソースの削除は、4 日目の演習 06 の「クリーンアップ」でまとめて行います。
